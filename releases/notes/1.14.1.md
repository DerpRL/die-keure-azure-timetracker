# Azure timetracker 1.14.1

- Track Figma designs, calendar meetings and branch suggestions without an Azure ticket. Unlinked suggestions open the activity chooser directly; suggested tickets can be switched off before Start.
- Figma uses the design file name as the 7pace comment, whether or not a ticket is selected. Ticket-free tracking preserves any saved file-to-ticket link.
- Suggestion ticket searches include Continue without a ticket. Meeting titles and branch names supply the comment for these suggestions. Activity selection and Start confirmation remain required.
- Removed Compare periods from Statistics. Time explorer, Tasks, Work patterns, heatmaps, timelines and the other charts remain available.

Update checks remain every minute. No tracking changes occur until you confirm them.
