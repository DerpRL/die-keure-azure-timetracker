# Azure timetracker 1.14.0

- Choose Light, Dark or System appearance, UI scale and contrast in Settings. New users see these choices in onboarding.
- Switch ticket now includes Meeting, Stand-up and Other activity. No ticket ID or title is required; choose an activity, optionally add a comment and confirm Start. Stand-up defaults to daily standup.
- Fixed missing local/offline timers: the overview and menu panel now show their live clock and Stop local timer action. The menu-bar clock shows local elapsed time when no confirmed remote timer is running. Local drafts remain separate from confirmed 7pace totals.
- Added optional Figma Desktop detection with file-to-ticket links, Design suggestions, last-worked context and a local history. Enable it on the Figma page and grant Accessibility. No Figma token, plugin, browser tracking or design-content access. Every timer change requires confirmation.
- App builds now use a persistent local signing certificate. This is not Apple Developer ID or notarization. The first migration from an older build may require approving Keychain, Calendar or Accessibility again; later builds reuse the same certificate.

Update checks remain every minute. This update does not automatically start or stop timers or upload local drafts.
