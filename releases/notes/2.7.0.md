# Azure timetracker 2.7.0

- Stopping a timer right after starting it works again. Before, stopping within a few seconds could fail with "Your timer changed in 7pace or another app".
- Development and Review are now at the top of the activity list when you start or switch a ticket. Your default activity is still preselected.
- The running timer shows its activity, for example Development, in the main window's top bar, the menu bar panel and the mini timer.
- In onboarding, ticking five or more repositories no longer makes the repository dialog jump up.

Update checks remain every minute. This update does not automatically start, pause or stop timers, and does not change tracked time.
