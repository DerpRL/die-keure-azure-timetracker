# Azure timetracker 2.3.0

- Setup is now its own four steps: Appearance & readability, Azure DevOps and 7pace, Git repositories and Figma, and Calendars (three steps on Windows). Each step saves as you continue, and finishing opens Today.
- The account step comes prefilled with diekeure-webdev, LK2020 and the 7pace workspace, and explains how to get the 7pace Mobile PIN approved or an API token.
- Test and save checks your Azure DevOps token before saving it and says what is wrong: an expired token, a missing permission, an unknown organization or project, or no connection.
- Settings only asks to save when something actually changed.
- Links to other sites, such as the 7pace workspace, open in your browser instead of inside the app.

Update checks remain every minute. This update does not change tracked time or automatically start, pause or stop timers.
