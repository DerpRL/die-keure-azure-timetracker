Updates from GitHub

• Check for new versions at startup and every six hours, or manually in Settings → App.
• See an update notice in the overview and menu-bar panel, with release notes and download progress.
• Download a verified update, then choose Install and restart when ready. Your 7pace timer keeps running.
• Invalid downloads are rejected. The installer preserves the previous app and restores it if replacement or launching fails.

Install version 1.13.0 manually once to enable this update system. Later versions can be installed from the app when its installation folder is writable. Protected locations can still require the regular DMG/PKG installer.

The app remains ad-hoc signed and is not Apple-notarized. Release verification authenticates our updates; it does not replace Apple Developer ID signing or guarantee that macOS permission prompts disappear.
