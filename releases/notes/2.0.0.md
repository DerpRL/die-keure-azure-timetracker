# Azure timetracker 2.0.0

- Azure timetracker is rebuilt from the ground up and now also runs on Windows. Every 1.14.2 feature stays: tracking and suggestions, offline drafts and the local timer, Time editor, statistics, weekly report, day review, targets and Figma context.
- On first launch, 2.0 imports your settings, history, offline drafts and edit history. The 1.14 files stay untouched.
- Suggestions no longer take keyboard focus by default. In Settings > Notifications, choose per suggestion type: Off, Notify only, Open panel or Open and focus.
- Turn individual features on or off in Settings > Features.
- Press ⌘K (Ctrl+K on Windows) for the command palette and ? for every keyboard shortcut. The ⌘-number shortcuts now follow the sidebar order.
- Git branch changes are noticed in about half a second.
- Every chart can be shown as a table, and every page works with the keyboard and VoiceOver.
- Slack huddle detection, unused since 1.7, is removed.
- 2.0 is signed with the same local certificate as 1.14.x, so saved credentials and Calendar and Accessibility permissions should carry over. If macOS asks, approve once.

Update checks remain every minute. This update does not change tracked time or automatically start, pause or stop timers.
