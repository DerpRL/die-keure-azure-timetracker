Before installing

Quit an existing Azure timetracker instance before upgrading. Quitting this app does not stop a timer running in 7pace.

The app has no Dock icon. After opening it, use the app icon and timer in the menu bar to open Settings or Overview.

Your accounts

Connect 7pace using Mobile PIN pairing or an API token, and add an optional Azure DevOps PAT in Settings. Calendar access and notifications are optional and requested separately. Meeting detection reads local microphone-use metadata for selected apps (macOS 14.2+). It needs no Slack credentials or IDs and records no audio. Browser calls appear under the browser name. Microphone use and mute state are imperfect meeting signals; you always confirm a timer change.

Stand-up huddles use no Azure work item, activity Standup, and comment daily standup. Your 7pace workspace must permit tracking with a comment only.

Release information

This locally built release is not notarized. The app uses a persistent local signing certificate. The installer is unsigned. This is not Apple Developer ID trust, and permission approval may be required when migrating from the previous ad-hoc signature. Install only if you trust the sender. Read the supplied installation guide for Apple's supported opening procedure.

The universal app was built for macOS 14 or later. Runtime validation was performed on an Apple Silicon Mac; Intel Macs and older macOS releases have not been tested directly.
